# Decision Framework Skill

Evaluates multiple options against evidence and constraints using a structured multi-stage gate.

## Purpose
Turns raw growth, product, or strategic intelligence into recommendations for the Decision Agent.

## Core Process
1. Validate incoming options and context.
2. Filter through constraints (Stage 1 Gating).
3. Conduct Dominance Analysis.
4. Apply Decision Profile scoring (Stage 2).
5. Analyze Trade-offs, Uncertainty, and Sensitivity.
6. Return a single Recommendation.
