# Uncertainty Framework

All evidence supporting options must be explicitly classified to prevent soft opinions from being represented as hard data.

## Evidence Taxonomy

| Type | Definition | Example |
|---|---|---|
| **FACT** | Verifiable immutable truth. | Company is registered in Delaware. |
| **OBSERVED** | Empirically measured results or data. | Outbound generated 12 customers last Q. |
| **INFERENCE** | Logical deduction from observed facts. | High churn is likely due to lack of onboarding. |
| **HYPOTHESIS** | An unproven proposal requiring validation. | Partnerships will scale more efficiently. |
| **ASSUMPTION** | A belief accepted as true without proof. | Partnership CAC will be 30% lower. |
| **UNKNOWN** | Explicitly missing data or parameters. | Competitor pricing for new tier. |
